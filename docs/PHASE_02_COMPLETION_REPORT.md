# گزارش تکمیل پیاده‌سازی فاز ۲: ساختار اصلی وب‌سایت

**تاریخ:** ۲۰۲۶-۱۱-۰۳ · **شاخه:** `arena/daf2c49b-equation-quest` · **وضعیت:** پیاده‌سازی و آزمون محلی انجام شد؛ پذیرش مالک و مجوز فاز ۳ هنوز صادر نشده است.

## مجوز، دامنه و تحویل

مالک تکمیل فاز ۱ را پذیرفت و جداگانه «فاز ۲: Core Website Structure» را مجاز کرد (D17). نسخهٔ حاضر Vite + React + TypeScript سخت‌گیرانه، React Router با HashRouter و `base: '/equation-quest/'`، صفحهٔ مشترک فارسی RTL، ناوبری دسکتاپ/موبایل، لینک پرش به محتوا، بازگشت با مسیر امن، و صفحات مستقلِ قابل پیوند مستقیم را فراهم می‌کند. هر کدام از ۹ موضوع، ماژول ورودی جدا و یک نمای مقدماتی مشترک دارند؛ این نما **درس یا تمرین تعاملی نیست**. `/world` چهار منطقه و ۸ مسیر مرحله را معرفی می‌کند؛ `/game` و `/progress` به‌ترتیب توضیحِ بازیِ در دست ساخت و حالت خالیِ صادقانه را نشان می‌دهند. مسیر ناشناخته یا شمارهٔ مرحلهٔ نامعتبر به صفحهٔ راهنمای ۴۰۴ می‌رسد. نمایش بارگذاری و خطای بارگذاری مسیر نیز وجود دارد.

صفحهٔ خانه دارای ساختار رواییِ معرفی، اهداف، مسیر، نقشه، روش یادگیری، راهنما، گردونهٔ موضوع‌ها و دعوت به ادامه است. گردونهٔ وب با CSS و motif ترازو از نمونهٔ Expo **فقط الهام بصری** گرفته است: دکمه، نشانگر، کلید جهت و حرکت اشاره‌گر دارد و لینک فعالش به موضوع واقعی می‌رود. این کار نه کد Expo است، نه بازی سه‌بعدی و نه روایت سینمایی GSAP فاز ۳. حالت کم‌حرکتِ UI از طریق Zustand در `localStorage` ذخیره می‌شود؛ هیچ XP/پیشرفت بازی ساختگی ذخیره نمی‌شود.

**فایل‌های اصلی:** `index.html`, `vite.config.ts`, `tsconfig.json`, `src/app/`, `src/components/{layout,navigation,carousel,ui}/`, `src/pages/{Home,Learning,Lessons,World,Game,Level,Progress}/`, `src/data/`, `src/store/`, `src/styles/`, `src/test/`. بسته‌ها با نسخه‌های پیشین قفل شده‌اند؛ وابستگی تازه‌ای اضافه نشده است. راهنمای معماری، مسیرها، وضعیت، حافظه، چک‌لیست و گراف استخراج‌شده به‌روز شدند.

## بازبینی anti-slop و دسترسی‌پذیری

**Design Read:** مسیر قبلی `docs/DESIGN.md` و وایرفریم‌ها، نشانهٔ ترازو و پالت سرمه‌ای/کرم/نعنایی/طلایی را تعیین کرده‌اند. دکمه‌های جهت‌دار جهت پیمایش RTL را نشان می‌دهند؛ گرادیان محدود به تصویرِ سرزمین و کارت شیشه‌ای گردونه برای عمق/کانون انتخاب است. ENERGY=۲، RHYTHM=۳، MOTION=۱ در این زیرمجموعهٔ ساختاری (هدفِ MOTION=۲ در `docs/DESIGN.md` برای فاز ۳ باقی است): تیتر قهرمان پررنگ، بخش‌های متن/فهرست/کارت با فاصله‌های متفاوت، تنها حرکت کوتاه تغییر کارت و امکان خاموشی آن.

- **Hard gate، بررسی ایستا/خودکار: PASS با محدودیت.** مسیرها و کنترل‌های اصلی با آزمون تعامل فعال‌اند؛ منوی موبایل وضعیت صحیح دارد؛ خطا/بارگذاری/حالت خالی مشخص است؛ `lang`, `dir`, `<title>`, focus/skip و `prefers-reduced-motion` موجودند. برای نمونه، اسکریپت کنتراست نسبت `#405369` روی `#f7f5f0` را `7.25:1`، `#715019` روی `#f7f5f0` را `6.73:1`، متن روشن روی سرمه‌ای را `11.25:1` و متن کارت روی تیره‌ترین حدِ روشنِ گرادیان را `6.25:1` گزارش کرد. پس از کشف نسبت ناموفق `3.85:1` روی رنگ روشن قدیمی کارت، گرادیان تیره شد. ناحیهٔ هدف نشانگرهای گردونه و دکمه‌ها حداقل ۴۴px تعریف شد. این‌ها بررسی نمونه‌ای هستند، نه ممیزی جامع WCAG.
- **Purpose/liveliness/craft: بررسی کد PASS.** کارت شیشه‌ای فقط در گردونه است، تصویر جزیره‌ها مفهومی و متناسب با داستان جبر است، عددهای ۰۱ تا ۰۸ شمارهٔ مرحله‌های مستندند نه آمار ادعایی، متن پیشرفت و بازی به‌وضوح نبود داده/عملکرد را بیان می‌کند و از نظر محتوا لینک بی‌مقصد یا نظرِ جعلی وجود ندارد.
- **گیت مرورگر واقعی: بررسی‌نشده.** در این sandbox فایل اجرایی مرورگر Playwright/Chromium یافت نشد. آزمون jsdom و بررسی media query جای مشاهدهٔ واقعیِ عرض‌های موبایل، لمس روی دستگاه، screen reader، overflow، مرورگر بدون WebGL یا click-through دستی تمام کنترل‌ها را نمی‌گیرند؛ بنابراین تأیید کامل بصری/دسترسی‌پذیری anti-slop یا سازگاری واقعی GitHub Pages ادعا نمی‌شود. پیش از پذیرش نهایی بصری/انتشار باید انجام شود.

## بدهی و توقف

`npm audit --json` همچنان **۱۶ آسیب‌پذیری (۲ کم، ۱۴ متوسط)** را گزارش می‌کند؛ ارتقای اجباری و بررسی‌نشده انجام نشد. بازبینی واقعی برنامهٔ درسی پایهٔ هفتم و متن فارسی نیز هنوز صورت نگرفته است. استقرار عمومی/Pages، تست E2E مرورگر، درس‌ها، موتور کسر دقیق، محیط سه‌بعدی، کنترل بازیکن، مراحل قابل بازی، XP و ذخیرهٔ پیشرفت خارج از فاز ۲ هستند. این گزارش درخواست تأیید نتیجهٔ فاز ۲ است، **نه مجوز شروع فاز ۳**؛ پس از ارائه متوقف می‌شویم.
