# Educational content plan — grade seven

## Concept sequence
1. Equation: equality of two expressions; `=` is a relationship, not a command to compute.
2. Unknown: `x` is a value to determine; coefficient and constant distinguished using boxes/objects.
3. Equality: adding/removing equal weights on both pans preserves balance; unilateral changes break it.
4. Inverse actions: addition↔subtraction, multiplication↔division; apply to **both** sides.
5. Solve: isolate `x` via a sequence of equivalent equations.
6. Verify: substitute into original equation; check both sides equal.

## Worked interaction
For `2x + 4 = 12`, select subtract four from both sides → `2x+4-4=12-4` → `2x=8`; divide both sides by two → `2x/2=8/2` → `x=4`; substitute: `2(4)+4=12`. UI shows state before/after each action, not only answer. KaTeX display isolated LTR. Prompts in Persian use seventh-grade vocabulary.

## Feedback ladder
First wrong operation: reflect concrete imbalance, ask what cancels the constant. Repeated error: highlight the term to undo; third request: show operation choice, not answer. For only-one-side operation: show both pans and ask what changed. For sign reversal: show inverse pair; for zero coefficient/division: refuse undefined action and explain. Correct: explain invariant, animate environment, award once and unlock. No timeout/negative XP.

## Review and assessment
Author each level with `objective`, misconception prompts, scaffold steps and verification expression. Test hints on positive/negative coefficients and non-integer solutions. Teacher review for curriculum and natural Persian wording is an open external validation item, not claimed complete.
