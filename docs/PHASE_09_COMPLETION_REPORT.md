# Phase 9: authentic world image, action surfaces and scroll narrative

**Implemented on `arena/5e702cfc-equation-quest`, 2026-11-03.** Owner authorized Phase 9 after merging Phase 8 PR #8. This report is local verification, not owner acceptance, a PR merge, a public deployment or Phase 10 authorization.

## Direction and decisions during implementation

Design read: `docs/DESIGN.md` specifies an enchanted instrument for reasoning, balance-beam symmetry, navy/ivory/gold, Vazirmatn, ENERGY 2 / RHYTHM 3 / MOTION 2. I read the vendored `antislop` core plus UI, layout/mobile, human, copywriting and code rules while building; the user's earlier instruction explicitly specified use **during** optimization. This work is not a blank-slate theme. Decisions and reasons:

- **Real scene art (R-23/R-31):** photographed pixels of the running `src/three/ExplorationScene.tsx` WebGL canvas in local headless Chromium (1440×900 viewport at DPR 2). Two crops from that actual canvas, saved as self-hosted WebP, occupy the Home hero picture and the Home's world-preview background. The left-hand hero text stays on solid navy; the world-preview gets a dark scrim. No generated fantasy/stock asset and no external image request. A static image works without WebGL.
- **Action-only optical edge (R-10/R-11/R-31):** navy/gold/ivory buttons and boxed CTAs gain a narrow inner highlight and restrained shadow; a subsequent stability pass removed global control backdrop blur, not glazed text cards or every page surface. 9px corners, native controls, 44px targets, solid background and keyboard focus remain. Only the decorative carousel lens retains optional desktop blur; mobile/reduced motion disables it. `reactdrops.dev` was **not imported or licensed**: a local CSS treatment is cheaper and avoids unreviewed code.
- **Scroll as a reading cue (R-19/R-31):** selected Home chapters and lower Learning, lesson, World, Game and Progress sections enter with a 570ms opacity entry (the container translation was removed after a reported scroll jump) and only short headings get a 1.15s stepped RTL clip reveal. `Intl.Segmenter('fa', {granularity:'grapheme'})` sets timing without splitting text nodes or touching KaTeX. Real heading text, focusable links and all sections exist and remain visible after React mounts, before the observer callback; effects are one-shot per entry. Stored and OS motion preferences and unavailable observer leave full content visible. Home's previous GSAP heading shift was removed to avoid doubling transforms; its separate hero parallax remains.
- **Truthful copy (R-16/R-36):** replaced the Home's obsolete “interactive game will be built later” language with descriptions of actual eight playable stages and verification. No fabricated usage counts or rewards.

## Measurements and verification

- Self-hosted desktop 1600×1092 WebP **32,900 bytes**; mobile 800×710 WebP **17,570 bytes**. `picture` chooses the mobile crop at <=900px; desktop and mobile use the same actual canvas composition. Budget script `npm run check:phase9` enforces 45,000/25,000-byte image caps plus a 260,000-byte gzip lazy scene cap. Built lazy scene: **242,737 gzip bytes** (925.41 kB uncompressed/minified), still warned about by Vite; it remains dynamically imported only by the 3D Game path, not Home/lessons/no-WebGL. This is an existing optimization limit, not falsely reported as a reduced bundle.
- WCAG contrast computed against **every pixel** of the desktop WebP under the weakest world-preview scrim opacity (0.85): `#e8eeee` body text worst-case **8.66:1**, `#e9b968` accent **5.62:1**; navy on gold **7.97:1**. Browser test independently samples the image and checks both against 4.5:1. This is scoped to the new image/controls, not a certified whole-site audit.
- One local **headless Chromium 153** mobile 390px, DPR 1 scroll sample with CPU throttled ×4: 135 `requestAnimationFrame` intervals, median 16.6ms, p95 **18.4ms**, maximum 36.9ms; CDP `LayoutDuration` 0.138s and `RecalcStyleDuration` 0.046s over the sample. This is a repeatable *local synthetic sample*, not physical mobile FPS, a comparative baseline or a device guarantee. Blur is intentionally disabled at mobile widths.
- `EXPECTED_BRANCH=arena/5e702cfc-equation-quest bash scripts/verify-environment.sh --full`: PASS (lint, formatting, TypeScript, **90/90 Vitest**, build). `npm run check:phase9`: PASS.
