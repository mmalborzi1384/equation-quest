# Balance lesson

**Status:** Draft / awaiting owner approval. Portable specification; implementation branch is assigned per Arena session.

## User story
As a seventh-grade learner, I can use this feature to understand and practice equations without creating an account.

## Requirements
Student adds/removes weights on either pan, observes equality change and can restore balance before entering level 01.

## Scope and constraints
R3F balance with accessible numeric control fallback; lesson-specific state/feedback. Persian RTL, mathematical LTR, desktop/mobile, accessible and usable without backend. Shared navigation and no dead controls. Refer to PRD, ROUTES, EDUCATIONAL_CONTENT and constitution for cross-cutting requirements.

## Acceptance evidence required
weight operations, reset, equality explanation, touch and keyboard fallback. Do not mark completed without implementation, tests and anti-slop delivery gate.
