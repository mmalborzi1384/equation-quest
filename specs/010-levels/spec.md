# Eight authored levels and unlocks

**Status:** Draft / awaiting owner approval. Portable specification; implementation branch is assigned per Arena session.

## User story
As a seventh-grade learner, I can use this feature to understand and practice equations without creating an account.

## Requirements
Levels 01–08 each teach distinct objective, gate on demonstrated action, award once and unlock next stage.

## Scope and constraints
Authored typed data per level, level manager, puzzle goals and scene mechanisms per island. Persian RTL, mathematical LTR, desktop/mobile, accessible and usable without backend. Shared navigation and no dead controls. Refer to PRD, ROUTES, EDUCATIONAL_CONTENT and constitution for cross-cutting requirements.

## Acceptance evidence required
one E2E solve/verify per level; locked order and reward idempotence. Do not mark completed without implementation, tests and anti-slop delivery gate.
